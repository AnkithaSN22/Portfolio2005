Next-Generation Network Intrusion Detection System
Problem Statement

To develop an intelligent Network Intrusion Detection System that can analyze network traffic, detect malicious activities, reduce false positives, handle imbalanced network traffic distributions, and provide understandable, explainable AI explanations for security analysts.

Key Features & Solution
  • Automated network traffic inspection and abnormal pattern classification.
  • High-accuracy Machine Learning pipeline combining XGBoost, Random Forest, and CNN.
  • Imbalanced dataset handling using advanced sampling techniques.
  • Explainable AI (XAI) integration using SHAP and LIME to interpret feature importance for every alert.
  • Tested on benchmarks: CICIDS2017, UNSW-NB15, and NSL-KDD.
